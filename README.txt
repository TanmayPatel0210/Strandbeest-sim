*README*
Strand Beest Simulator:
This is an Interactive Simulator/Learning Website which teaches about the Basics of a strand beest. 
The website is mostly about the Jensen's Linkage
This was built from scratch in one week for #horizon

How to open:

To access it go to the url: https://tanmaypatel0210.github.io/Strandbeest-sim/
OR 
you could clone/download the repository and open index.html in any browser

PAGES:

Home — Navigation to all sections of the website
Learn Jansen's Linkage — Single leg simulator with speed control showing the original Jansen's Linkage
The Holy Numbers — Story of how Jansen found the 13 ratios of rod lengths called "The Holy Numbers"
Sandbox — Tweak all rod lengths in real time and see how the foot path changes
Full Strandbeest — 4 leg simulation with phase offsets showing actual walking coordination
My Journey — Personal Experience of building this from scratch

Built With:
VS code
HTML
CSS
Java Script

Working:
HTML canvas for the rendering 
Javascript for the actual calculations and drawing
Circle-circle intersection formula for calculating the points
simple trignometry for drawing
